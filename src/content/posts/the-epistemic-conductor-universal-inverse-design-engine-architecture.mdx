# Introduction: The Failure of Forward Biological Discovery

Contemporary drug discovery and biomedical research operate on an inefficient **forward-search heuristic**: scientists screen millions of candidate small molecules or sequence thousands of genomes hoping to stumble upon a functional interaction. 

This forward trial-and-error paradigm yields diminishing returns because biological systems are hyper-dimensional, non-linear, and burdened by evolutionary baggage.

The **Universal Inverse Design Engine (`uid-engine`)** replaces forward trial-and-error with **Inverse Causal Mapping**.

```text
FORWARD SEARCH (Slow, Low-Probability):
[Random Library Screening] ──> [Candidate Testing] ──> [99% Clinical Failure]

INVERSE DESIGN (Deterministic, Goal-Driven):
[Desired Physiological State] ──> [Causal Chain Inversion] ──> [Negative Space / Gap Detection] ──> [Targeted Synthesis]
```

Instead of asking *"What do existing biological databases tell us?"*, the engine asks:

> **"What must exist for a specific physiological repair goal to be mathematically true, and where does current human knowledge possess a topological hole?"**

# Part 2: The Mathematical Graph Ontology (`schema.py`)

The engine structures all biological knowledge into a typed directed graph `G = (V, E, W)`:

- `V` is the set of typed nodes representing physical or conceptual entities.
- `E` is the set of typed, directed causal edges representing biological relationships.
- `W: E -> [0, 1] x {PROVEN, HYPOTHESIZED, FAILED}` assigns a confidence score and validation state.

### 1. Node Taxonomy (`V_type`)

```text
V_type in {
  MOLECULE,      // Small molecules, crosslinks, xenobiotics
  PROTEIN,       // Enzymes, structural collagen/elastin
  GENE,          // Genetic loci, coding transcripts
  PATHWAY,       // Biochemical signaling circuits
  TISSUE,        // Human organs (arteries, skin, kidney)
  PAPER,         // Peer-reviewed publications (PMIDs)
  DAMAGE_CLASS,  // SENS 7 Aging Damage Categories
  MECHANISM,     // Biochemical reactions
  UNKNOWN        // Negative Space: Explicit Knowledge Voids
}
```

### 2. Edge Taxonomy (`E_type`)

Every edge `e = (u, v)` represents a directed assertion:

```text
E_type in {
  CATALYZES,     // Enzyme -> Reaction
  CROSSLINKS,    // Molecule -> Structural Protein
  CAUSES_DAMAGE, // Mechanism -> Tissue Pathology
  REPORTED_IN,   // Entity -> Literature Source
  REQUIRES,      // Upstream Prerequisite -> Downstream Goal
  PART_OF,       // Entity -> Metabolic Circuit
  INHIBITS,      // Regulatory Suppression
  ACTIVATES,     // Upstream Induction
  DEGRADES,      // Enzymatic Hydrolysis / Cleavage
  PRODUCES,      // Reaction Product
  BLOCKS         // Physical / Chemical Obstruction
}
```

### 3. Confidence Decay Matrix

Edge weights `c(e)` are assigned based on evidentiary provenance:

```text
c(e) = 1.0  ──> Curated Database (UniProt Swiss-Prot, KEGG verified)
c(e) = 0.8  ──> Structured Bioassay (ChEMBL Ki, IC50 values)
c(e) = 0.5  ──> LLM-Extracted Literature Assertion (Single Abstract)
c(e) = 0.3  ──> Unreplicated Hypothesis / Computational Model
```

When an edge is tagged as `FAILED` (e.g., *Enzyme X tested and failed to hydrolyze glucosepane*), its effective traversal weight is zeroed for forward positive chains (`c_eff = 0`), preventing false-positive causal propagation.

# Part 3: Overcoming the "Regex Delusion" in Entity Extraction (`entities.py`)

A foundational vulnerability in traditional bio-NLP systems is the **Regex Delusion**—the naive assumption that keyword co-occurrence equals biological causality.

Consider this authentic biomedical abstract sentence:
> *"Unlike bacterial collagenase, candidate enzyme Glyc-1 failed to hydrolyze the glucosepane amidine ring in vitro."*

- **Naive Keyword Matching:** Flags `(Glyc-1) ──[CATALYZES]──> (Glucosepane)`. **(Catastrophic False Positive)**
- **Engine Causality Parser:** Analyzes syntactic qualification and extracts:

```json
{
  "source_id": "protein:glyc_1",
  "edge_type": "DEGRADES",
  "target_id": "mol:glucosepane",
  "context": "candidate enzyme Glyc-1 failed to hydrolyze the glucosepane amidine ring",
  "status": "FAILED"
}
```

### Schema-Guided Extraction Contract

Abstracts from PubMed are passed to reasoning blocks with strict schema enforcement:

```json
{
  "entities": [
    {
      "entity_id": "mol:glucosepane",
      "type": "MOLECULE",
      "name": "Glucosepane"
    }

    {
```

# Part 4: Negative Space Detection Algorithm (`gap_detector.py`)

Let a desired physiological outcome (e.g., *Restoration of youthful arterial compliance*) be formalized as a root goal node `R`. We decompose `R` recursively into an **Inverse Causal Tree** `T = (V_T, E_T)`:

```text
[Goal: Restore Arterial Compliance]
   │
   └── [Req 1: Degrade Glucosepane Crosslinks]
         │
         ├── [Req 1.1: Selective Cleavage Catalyst]
         │     ├── [Req 1.1.1: 3D Crystal Structure of Complex]
         │     ├── [Req 1.1.2: In Silico Sub-Nanomolar Active Pocket]
         │     └── [Req 1.1.3: Modifiable Protein Scaffold]
         │
         ├── [Req 1.2: In Vivo ECM Delivery Vehicle]
         │     ├── [Req 1.2.1: Fibrotic Media Penetration]
         │     └── [Req 1.2.2: Serum Protease Stability > 24h]
         │
         └── [Req 1.3: Byproduct Safety & Remodeling]
               ├── [Req 1.3.1: Fragment Toxicity Characterization]
               └── [Req 1.3.2: Fibroblast Mechanical Restoration]
```

### Verification & Classification Function

For each node `n_i` in the causal chain, the detector checks the knowledge graph:

```text
Psi(n_i) = { v in V_G | match(v, n_i) AND exists e in E_G s.t. status(e) == PROVEN AND c(e) >= theta }

Gap(n_i) = 
  ├── MISSING_MECHANISM    if Psi(n_i) is empty
  ├── UNPROVEN_HYPOTHESIS  if match exists but status != PROVEN or confidence < theta
  └── NULL (Satisfied)     if condition is experimentally validated
```

### Severity Scoring Function

Every identified gap is scored by its downstream propagation impact:

```text
Severity(Gap) = PriorityWeight(n_i) * (1 + sum_{k in Ancestors(n_i)} 1 / depth(k))
```

Where `CRITICAL` = 4, `HIGH` = 3, `MEDIUM` = 2, `LOW` = 1.
